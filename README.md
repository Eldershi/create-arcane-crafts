# 机械动力：奥术工艺

Create: Arcane Crafts · Minecraft Java Edition 1.20.1 / Forge 47.4.10

**非 Minecraft 官方产品，未经 Mojang 或 Microsoft 批准，也与其无关联。**

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

将机械动力与铁魔法连接起来的独立附属 Mod。维护者：[Eldershi](https://github.com/Eldershi)；项目反馈：[GitHub Issues](https://github.com/Eldershi/create-arcane-crafts/issues)。本项目也不是 Create 或其他依赖模组的官方作品。

## 研发内容

- 奥术升华室、法术升级与超越、手动和动力加工。
- 随机研习、卷轴打印与注墨。
- 奥术／猩红原液、源质、砂轮回收和流体舱口。
- 背包奥术补给与 JEI 展示。

当前版本为 0.1.0 研发原型；内部注册命名空间仍为 `arcane_industry`。
