# 升华室卷轴揭示：游戏接入

已确认的 WebGL 轨迹用于真正的升华室方块实体渲染，不需要开启光影。

## 动画和声音

- 随机研习独立加工时长为 161 游戏 tick（8.05 秒，向上取整已确认的 8.014 秒）。其他手动工艺仍为 70 tick。
- 主副物品从下至上结晶、消散并向中心汇合；晶体固定随机大小和色差，不单独倾斜或描边。主体使用连续的双色噪声，六面用明暗表现体积。
- 主体随后留下对应原液颜色的亮卷轴剪影，保持缓慢的翻动和微浮，渐渐退光并归位。完成与待机共用绝对时钟的 ±0.008 格／4.8 秒浮动，书本和返还物也会归位。
- 主体 28 颗、副物品 40 颗细粒子；副物品一半吸附、一半扩散。史诗、传说额外有 48 颗延迟涡流，传说增加 12 个粗像素卢恩字符。更低品级没有这层完成特效；粒子设置会减少或关闭装饰粒子。
- 高两档采用已选的 09：原版 `block.beacon.activate`。其他工艺对应 CEI 2.5.4b 的附魔台／铁砧完成声，不再播放旧工作咒语。
- 手动工作火焰和壁面符文最高为方块内 Y=1.0；结束后烈焰人睁眼，头顶有工作盆／储罐时继续使用原工作闭眼姿态。

## 光效实现

`ChamberGlowRenderTypes` 复用原版 eyes shader，清晰核心采用普通 alpha 混合，极少量局部柔光采用 SRC_ALPHA + ONE。都使用 LEQUAL 深度测试、颜色写入和四边形排序，不替换全局后处理。亮度不依赖方块光照，也不会生成临时光源方块。

这提供原版渲染器中的自发光观感，不是屏幕 Bloom 或彩色环境照明。晶体不画轮廓线，单颗晶体保留种子决定的明暗／色调差异。

输入与输出读取当前物品模型、UV、颜色和透明覆盖，资源重载后重建缓存。没有复制依赖模组的图片或音频。缓存和固定几何数量限制每帧工作量；无逐帧纹理读回或全屏模糊。

完整原生 API 证据及兼容边界见 [光效审计](reveal-glow-audit.md)。

## 权属和验证

服务器先完成唯一抽取并持久化付费事务，客户端只读取快照。暂停和读档沿用原结果、随机种子和付费进度；161 tick 前不可提取。完成后快照仅供渲染，物品归属已转为结果槽，取走后清理快照。

下面是 2026-10-20 卷轴接入批次的结果，使用当时包含原型验收入口的集成构建。原始证据中记录的 JAR SHA-256 为 `c3586985895caa32f586f984c42229d13bb1804f2114a5ef128b413cf0f2d336`。最终发行将 QA 类拆至独立 `prototypeJar`；下方截图和完整画面检查不自动归属于重新打包后的正式 JAR。新生产包与原型包的构建、复跑结果和哈希分别见 [0.1.0 发布验收](releases/0.1.0.md) 与 [验收记录](releases/0.1.0-verification.json)。

- 标准 Gradle 8.8 `build`：通过，包含 refmap、生产重混淆和发布包校验。
- WebGL 动画对照：10,508 组、71,986 个数值通过，最大误差 4.89×10⁻¹⁴。
- 生产晶体布局对照：10 组、8,520 个数值通过，最大误差 5.56×10⁻¹⁷。
- 声音时间线：288 项通过，包含品级、首次晚期观察、暂停、回退及网络大跳。
- 真实隔离服务器：普通／猩红研究的 161 tick 交付、90/160 tick 重载、模板／工作盆／输出堵塞暂停、500mB 单次付费、可复用引导物、结果唯一归属全部通过。
- 原有升华室回归：47 项通过，普通 70 tick 升级、工作盆、费用边界、返还物和装饰行为保持。
- 真实登录配方包：3,229 个配方、17 个装配步骤、413,143 字节整包往返通过。修复 Create 网络流体标签不带 TagKey 时被错误写回 JSON 的断线问题；空标签和数据包扩展保持有效。
- 客户端 JEI：108 个印刷链、1,510 个升华链显示副本通过网络后克隆与 NBT／原液核对，原配方未被改动。
- 原生无光影客户端：检查金色／蓝紫色晶体和亮剪影、史诗／传说涡流与字符、低品级无额外完成特效、普通不透明墙遮挡、资源重载、日间／夜间和完整 8 秒动画归位。截图使用 Minecraft 的真实帧缓冲接口，未合成。

实测环境为 Minecraft 1.20.1／Forge 47.4.10、默认 Fancy 渲染与 Flywheel instancing；未安装光影模组。Fabulous、第三方光影、玻璃／水多层透明排序不属于这次已实测的范围。

原型对照工具在 `tools/verify-chamber-motion.cjs`、`tools/VerifyChamberSounds.java`、`tools/verify_scroll_reveal_layout.py`。前后两项依赖不分发的本地 WebGL `art/` 基准，布局工具另需原型离线编译类路径。普通克隆可运行的纯 Java 不变量检查和原型包测试方法见 [开发指南](DEVELOPMENT.md)。原始证据位于本地 `testing/reveal-integration-20261020/`，不会进入公开仓库或发布包。
