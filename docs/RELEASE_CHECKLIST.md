# 发布验收清单

每个发布版本保存一份 [0.1.0 示例记录](releases/0.1.0.md)，标明环境、产物 SHA-256、证据来源和未覆盖项。实现经验见 [开发指南](DEVELOPMENT.md)。以下勾选项用于后续版本复核，不能仅从本文件的存在推断已通过。

## 自动构建

- [ ] JDK 17，固定 Gradle Wrapper、ForgeGradle 和依赖版本；普通干净克隆可运行 `./gradlew clean build`。
- [ ] `verifyReleaseInvariants`：权威时钟、暂停／回退、收尾连续性、待机接续、四元数和有限数值、抽取品级、音效游标。
- [ ] `verifyReleaseJar`：版本、Mixin/refmap、生产映射、JSON、许可一致、仅 8 张原创 PNG，无上游素材／嵌套依赖／QA 类。
- [ ] `./gradlew prototypeJar` 可构建，测试包和正式包不同时安装。
- [ ] `git diff --check` 通过；CI 从公开提交重新构建，报告和产物可下载。

自动报告位于 `build/reports/release-invariants.json` 与 `build/reports/release-jar.json`。构建检查不代替游戏联网和实际绘制。

## 隔离游戏验收

只使用独立测试目录、一次性平坦世界和已合法安装的依赖。测试命令会改动固定区域；通过服务器控制台执行，无需修改玩家权限。

- [ ] 原型包启用 `-Darcane.prototype=true`，运行 `arcane_recipe_network_test`、`arcane_research_test`、`arcane_chamber_test`，保留三份 JSON 报告。
- [ ] 研究付费一次、蓝／红原液、引导物复用、90／160 tick 存读、缺模板／上方工作盆／输出阻塞暂停，以及提取／拆机唯一交付。
- [ ] 普通卷轴／书内法术／超越升级、原生铁砧、输出堵塞／取消／读档回归。
- [ ] 整包配方真实网络往返；空／扩展流体标签；JEI 登录深克隆不改 RecipeManager、不共享可变步骤、严格保留 NBT。
- [ ] 正式包启动独立服务器；真实客户端连接、配方同步及 JEI 加载成功。即使误留 prototype 开关，正式包缺少测试类也能安全启动。

## 画面与声音

- [ ] Fancy、无第三方光影，记录 Flywheel 后端和粒子设置；日／夜下检查金色及各学派颜色。
- [ ] 晶体大小／蔓延／轮廓、晶体间色差、六面明暗和主体柔和噪声；不出现描边或穿墙发光。
- [ ] 主副物品汇合姿态、粉尘吸入与消散、亮剪影缓慢退光、完整收尾、连续升级回到待机浮动。
- [ ] 低品级无完成涡流，史诗有涡流，传说增加卢恩；减少／最少粒子设置有降量。
- [ ] 工作火焰不超过一格；手动完成恢复睁眼，上方工作盆／储罐保留原生姿态。
- [ ] 普通工艺沿用对应 CEI 声音，高两档完成声使用选定方案 09；暂停、晚观察和进度回退不重复补播。
- [ ] 不透明墙完全遮挡；资源重载后贴图、模型和遮罩缓存恢复。
- [ ] Fabulous、玻璃／水透明排序和第三方光影分别记录结果，未测就明确标记。

## 发布

- [ ] 区分历史完整 QA 验证、当前原型复跑和当前正式包 smoke；每项绑定实际产物哈希。
- [ ] 正式 JAR、源码包、SHA256SUMS 和更新记录一致，测试包不作为普通安装包上传。
- [ ] 清点自有／派生资源及许可；排除依赖 JAR、存档、截图、启动元数据、账号与本机缓存。
- [ ] 从公开 Git 历史创建提交；本地原型受限历史不推送，不强制覆盖远程。
- [ ] 推送版本标签与 GitHub Release，核对下载附件哈希、源码指向和 CI 结果。
