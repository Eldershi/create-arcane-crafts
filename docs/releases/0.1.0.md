这些截图属于当时的完整 QA 包，不能标为当前正式包的截图。本轮在剥离 QA 后重跑原型服务器回归及正式包启动／登录检查，并核对正式／原型生产类一致。原 WebGL 轨迹对照记录为 71,986 个数值，最大误差 4.89e-14；布局对照 8,520 个数值，最大误差 5.55e-17。

## 后续自动验收

[GitHub Actions](https://github.com/Eldershi/create-arcane-crafts/actions/workflows/build.yml) 从公开提交的干净检出执行：

```sh
./gradlew --no-daemon --max-workers=2 clean build prototypeJar
```

成功构建保存正式包与源码包；验收报告另行保存。CI 验证可移植构建与发布约束，游戏检查仍需按清单单独执行。查看对应提交／标签的运行结果；不从本地构建结果推断远端 CI 已通过。

同一任务的版本标签重建曾发现：默认编译缓存只恢复类文件，未恢复 Mixin AP 写在临时目录的 refmap，导致 JAR 检查正确拒绝发布。0.1.0 的最终构建配置显式声明原始 refmap、用于打包的命名副本及额外 SRG 映射；CI 第二轮清理构建目录后，要求日志实际出现 `compileJava FROM-CACHE`，并重新验证生产包和原型包，防止冷构建成功掩盖缓存缺陷。该修正不改变已验收的游戏业务代码。

公开提交沿用已有的公开 Git 历史，不包含早期本地受限素材历史。发行物仅含 8 张原创 PNG，不含依赖 JAR、复制的上游音频、测试世界或启动元数据；许可与引用声明随 JAR 一同分发。
