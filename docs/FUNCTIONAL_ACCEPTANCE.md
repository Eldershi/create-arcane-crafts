# 全功能操作验收

这份清单按当前源码列出实际操作与预期，供维护者和玩家逐项测试。所有框初始为空；勾选表示在记录的构建和环境中实测通过，不能用旧版报告代替。历史发布验收保留在 [`releases/`](releases/0.1.0.md)，自动验收入口和打包要求见 [发布清单](RELEASE_CHECKLIST.md)。

测试前记录：日期、JAR 的 SHA-256、Minecraft／Forge／Create／CEI／铁魔法版本、资源包、光影、Flywheel 后端、粒子设置、单人或专服。先在备份后的独立测试世界操作。涉及雷击、拆机和死亡的项目另设空地；禁止拿生产存档直接跑原型指令。

拼音搜索、Jade 和 BSL 是测试实例另外安装的可选组件，不是本模组内置或随包分发的功能。没有安装时，将对应兼容项目记录为“不适用”，不能据此判定本模组功能缺失。下面分为 14 类；一项若包含两种模式或容器，需分别记录实际结果。

## 01 安装、合成与配方入口

- [ ] 仅安装一份本模组和固定依赖进入世界；加载成功，无缺类、Mixin 或配方同步异常。
- [ ] 分别用中文全名、英文名查找本模组物品；JEI 能找到对应注册物品，不出现重复幽灵条目；额外安装拼音搜索后另验拼音查询。
- [ ] 按 JEI 合成升华模板；得到模板物品，原材料与配方一致。
- [ ] 在原版锻造台放升华模板 + 烈焰人燃烧室（`create:blaze_burner`）+ 奥术铁砧（`irons_spellbooks:arcane_anvil`）；得到奥术升华室，模板仅作为合成材料使用。
- [ ] 放置刚合成的升华室，不另装模板；有效配方可运行。
- [ ] 尝试右键及漏斗新装升华模板；机器拒收，手中或管道余量不丢失。
- [ ] 按 JEI 分别合成奥术砂轮、奥术分液池、奥术舱口、奥术补给升级；每种得到对应物品。
- [ ] 纸与线合成空白卷轴；得到铁魔法原生空白卷轴，可用于研习与打印。
- [ ] 按蛋 → 糖 → 余烬源质 → 压制 → 猩红原液步骤制作余烬蛋糕；中间件顺序、耗材与最终结果一致，未完成中间件不能充当成品。

## 06 卷轴与书内法术升级

- [ ] 已写卷轴与目标品级墨水、足量原液手动升级；70 tick 后只提升一级，消耗一瓶墨水并返空瓶。
- [ ] 换错误品级墨水；插入组合被拒绝，强制旧存档组合也不能加工，不吞卷轴和液体。
- [ ] 普通原液做 7 → 8 级；不得加工；同一合法物品组合仍允许等待猩红原液。
- [ ] 猩红原液做 7 → 8 级；本次基础费 250 mB，实际计价 62.5 mB；无旧余量时先扣 63 mB 并保存半 mB 余量，不取整获利。
- [ ] 原生最高级卷轴没有蛋糕时；不消耗材料，不突破。
- [ ] 配齐猩红原液、蛋糕和有效避雷针进行突破；每次只升一级，费用和蛋糕消耗正确。
- [ ] 升到原生上限 +3 后再升级；拒绝，完整保留输入。
- [ ] 用低原生上限法术做突破；根据该法术真实上限处理，不固定认为 10 级才需要蛋糕。
- [ ] 法术卷轴含名字、附魔或其他 NBT；升级只改目标法术等级，其他标记与锁定状态保留。
- [ ] 靠近并瞄准带多种法术的书；自动出现铁魔法样式的选术栏，滚轮可切换有效法术，中键确认选择。
- [ ] 中键确认有效槽并等待书合拢；仅指定槽升一级，其他槽、空槽、法术锁定和书本 NBT 保留。
- [ ] 未确认、取消选术或选择空槽；不启动、不扣墨水、不保留上次书的陈旧选择。
- [ ] 换书后使用旧选择包，或隔墙／超距离操作；服务器拒绝，不升级错书或错法术。
- [ ] 书升级时观察开合、翻页、归位；完成收尾后重新打开，书本位置稍低、朝玩家一侧略下倾且不碰笼架；取回空瓶后不取下书，重新选术加墨，再升级一次。
- [ ] 书内法术升级或扩槽完成 24 tick 后仍留书在台上；书成品只移回主输入一次，保存重进仍可打开；空瓶及额外返还未领完时拒绝新材料，非书成品不自动移槽。
- [ ] 输出塞满后尝试升级；所有输入、原液和蛋糕原样保留。
- [ ] 在原生奥术铁砧用卷轴 + 墨水升级；目标低于 5 级且未突破时保持原生行为，目标达到 5 级或突破时不出结果、清除陈旧预览且不耗输入。
- [ ] 在原生卷轴锻造台尝试直接书写目标达到 5 级的卷轴；不出结果、不耗书写材料，低级原生书写仍正常。

普通未突破卷轴的基础原液费用：目标 2／3／4 级为 100／150／200 mB，目标 5／6／7 级为 250／500／750 mB。猩红按该基础价的四分之一计费；普通模式不接受目标 8 级以上。猩红目标 8／9／10 级的基础价重起为 250／500／750 mB，再应用四分之一；突破按原生上限与超出级数计算，不固定套 10 级法术表。研习固定 500 mB，不使用该折扣。

## 07 六类原生奥术铁砧操作

以下都使用当前安装铁魔法的原生规则计算结果；先在原生奥术铁砧确认同一对输入有效，再比较升华室输出。每次都应消耗一件主物品和一件副材料；主物品的变化结果作为成品返还，不能只耗液体留下原材料。普通原液每次 250 mB，猩红按 62.5 mB 记账并保留分数余量；工艺不要求突破蛋糕。

- [ ] 固有法术武器 + 同法术更高等级卷轴；只升级原有锁定法术，输出与原生菜单一致。
- [ ] 可注魔装备 + 法术卷轴；在正确空位／替换位写入法术，其他槽不被抹掉。
- [ ] 可升级装备 + 有效法球；增加对应属性与升级数，消耗法球，原生限制仍有效。
- [ ] 未达槽位上限法术书 + 扩槽材料；只增加一个槽，保留现有法术。
- [ ] 亲和戒指 + 法术卷轴；绑定对应法术，其他 NBT 保留。
- [ ] 有法术或属性升级的装备 + 洗炼石；清除对应内容并逐件返还所有原生法球，不能丢失额外返还队列。
- [ ] 已满升级／槽位、同级固有法术、重复不能写入的法术或不兼容材料；不接收错误组合，旧组合强行存在时也不能吞材料。
- [ ] 多次查看 JEI／选术／组合过滤再取消；真实输入 NBT、玩家背包与原生注册表返还模板保持原样。
- [ ] 洗炼完成后先取主物品、再逐个取多种返还；每个只拿一次，全部取完才清除结果事务。

- [ ] 接动力转动奥术砂轮；普通渲染和 Flywheel 轮体一致，r57 三段错齿结构没有缺面。
- [ ] 手持奥术砂轮右键空的原版分液池；改装为奥术分液池；原分液池有物品或流体时拒绝改装并保留内容。
- [ ] 用砂轮执行 CEI 原生修复、附魔去除、经验与抛光配方；行为与原生砂轮一致。
- [ ] 无动力送入待回收物；不会自动剥离法术或生成源质。
- [ ] 分液池干磨带法术物品；按每个可回收法术当前等级的原生品级计普通到传说 1／2／4／8／16 单位，每单位给一个奥术源质。
- [ ] 干磨普通法球和魔力法球；分别回收 8／24 单位源质，法球消失。
- [ ] 回收带属性升级的装备；按真实升级次数计量，装备及非目标 NBT 保留，不额外返一份法球。
- [ ] 回收固有法术装备或仅有空槽的书；固有默认法术、容量及空槽不产生可刷源质，清空后懒初始化不恢复法术。
- [ ] 水湿磨；每个回收单位严格消耗 250 mB 水并产生 250 mB 奥术原液。
- [ ] 血液湿磨；每单位消耗 250 mB 血液并产生 250 mB 猩红原液。
- [ ] 从分液池朝向的顺时针侧供试剂，逆时针侧抽成品；输入、输出及原生经验槽彼此不串液。
- [ ] 带正回收单位的物品遇试剂不足、原液输出满或源质槽满时；等待，不先剥离物品；已处理物品的未结算单位继续记账，不丢失。
- [ ] 加工开始后切换水／血液；当前事务模式固定，不混算或用另一种液体补付。
- [ ] 原生经验输出满或原生加工被取消；保留原物品，不绕过原生交易剥离法术。
- [ ] 自动化查询／模拟插入；不会启动加工或修改计时，实际插入只接受一件。
- [ ] 加工中自动化抽取；不能拿到未提交原料或半成品，完成后正常输出。
- [ ] 多单位回收中途保存／拆机／重新放置；剩余单位、试剂及回收原液随奥术分液池持久化，库存物品与已生成源质分别只掉一次，不从视觉快照再掉一份。
- [ ] 分液池上有物品和液面时观察；继续由原生渲染器显示，无缺失或双重绘制。

## 11 奥术舱口

- [ ] 把舱口装在储罐／升华室水平侧面；朝向附着方块，管道与容器交易能到达实际目标。
- [ ] 用蓝／红瓶桶分别向舱口倒入和取出；只交易完整 250／1000 mB，返还正确空／满容器。
- [ ] 目标无流体口、目标已拆、流体错误、容量不足或液量不够；无交易，不喝掉瓶、不在舱口外放一格水。
- [ ] 空手点舱口；不取升华室物品或头饰。
- [ ] 用扳手旋转、拆装、浸水舱口；朝向、水状态和原生交互正确。
- [ ] 用连续舱口接到目标，另构造错误朝向和循环；合法链路通，循环及时拒绝，不递归卡死。

## 12 饮用、站立与背包补魔

- [ ] 消耗魔力后对空气饮奥术原液瓶；32 tick 饮用后最多恢复 50 魔力，生存返空瓶。
- [ ] 对空气饮奥术原液桶；最多恢复 200 魔力，生存返空桶；指向方块时保留原版桶放置功能。
- [ ] 满魔、旁观或死亡时尝试补给；不消耗原液，不超过实际魔力上限。
- [ ] 在装有奥术原液的分液池表面站定；每 10 tick 最多使用 50 mB，按 0.2 魔力／mB 补给。
- [ ] 离开表面、骑乘或边缘无接触；不从远处分液池持续吸液。
- [ ] 身体同时接触相邻分液池；同通道冷却不叠加，不翻倍补给。
- [ ] 背包安装原生储罐升级、装入奥术原液并启用奥术补给升级，玩家有缺失魔力；在能触发 Sophisticated 原生升级调度的携带位置，每 20 tick 最多使用 25 mB，补 5 魔力，末次按缺失量封顶。
- [ ] 关闭补给升级、背包没流体升级、空罐或只有猩红原液；不补魔，不扣其他流体。
- [ ] 同一背包尝试装两个补给升级；限制为一个；同时带多个背包不叠加该通道速率。
- [ ] 补魔后比较原生铁魔法 HUD 和服务器数据；客户端同步一致，不维护第二个独立魔力池。

## 13 外观、头饰、雷击与死亡

- [ ] 生存模式用黄铜、秘银、铜锭分别右键换外壳；正确换皮并只付一个，重复同皮肤不再扣锭。
- [ ] 改皮时正在加工或有储液；配方、进度、物品与液体保持。
- [ ] 戴工程师眼镜或死灵冠；一次只展示一个，原物品完整 NBT 持久化。
- [ ] 已有头饰时再装同种或另一种；拒绝且不吞物品。
- [ ] 空手／潜行取回头饰；在对应机器物品／旧槽回收之后返还原件；创造模式也不保留额外复制件。
- [ ] 加工中空手点机器；不能取走输入、成品快照或头饰。
- [ ] 突破时有合格暴露避雷针；原生雷击由避雷针接走，正常付款交付。
- [ ] 突破时没有避雷针；按原生逻辑真实雷击并杀死烈焰人，失败交易不扣输入、原液和蛋糕。
- [ ] 死机器保存、拆掉再放；仍死，不靠放置复活；皮肤、装饰与火焰状态正确保存。
- [ ] 生存模式用装有烈焰人的原生燃烧室恢复死机器；消耗一个装载件并返空燃烧室，已活机器不能再消耗一件。
- [ ] 用铲子／空手左击扑灭空笼残火，再用打火石点燃；仅作用本笼，不误灭邻居的火。
- [ ] 雷击后移走／恢复机器；清理仅限机器上方短暂残火，不扫描清空周边火焰。
